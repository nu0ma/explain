クライアントとサーバーは3回のパケット交換で接続を確立する。そのあとでデータを送り始める。

## 3回の交換で双方向の通信路ができる {span=2}
```callout
クライアントがSYNを送り、サーバーがSYN-ACKを返す。最後にクライアントがACKを返す。この3回で、両側が互いの初期シーケンス番号を受け取ったと確認できる。
```

## パケットはSYN、SYN-ACK、ACKの順に流れる {span=2}
```sequence num
participants: クライアント, サーバー
note サーバー: LISTEN
== 接続の確立 ==
クライアント -> サーバー: SYN（seq=x）
note クライアント: SYN-SENT
サーバー --> クライアント: SYN-ACK（seq=y, ack=x+1）
note サーバー: SYN-RECEIVED
クライアント -> サーバー: ACK（seq=x+1, ack=y+1）
note クライアント, サーバー: ESTABLISHED
== データ転送 ==
クライアント -> サーバー: データ
```
xとyは、各側がランダムに選ぶ初期シーケンス番号です。

## 各パケットは1つずつ役割を持つ
| 順 | パケット | 送信側 | 役割 |
|---|---|---|---|
| 1 | SYN | クライアント | 自分の初期番号xを伝える |
| 2 | SYN-ACK | サーバー | xの受信を伝え、自分の初期番号yを伝える |
| 3 | ACK | クライアント | yの受信を伝える |

## 2回では足りない
| 確認する内容 | 2回 | 3回 |
|---|---|---|
| クライアントからサーバーへ届く | ok | ok |
| サーバーからクライアントへ届く | ok | ok |
| yが届いたことをサーバーが知る | no | ok |
| 古い重複SYNによる誤接続を防ぐ | no | ok |
